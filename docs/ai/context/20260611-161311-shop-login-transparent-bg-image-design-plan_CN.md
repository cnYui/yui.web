# `/shop/login/` 透明人物背景图

## 背景

- 用户提供 `/Users/wujianxiang/Downloads/2080.PNG`，要求用代码把白色背景抠成透明背景。
- 抠好的图片需要放到登录页背景正中间。
- 登录页标题改成“这里是登录页面”，整体不需要太正式。

## 设计

- 透明图输出到 `shop/assets/login/yui-login-bg.png`，作为项目静态资源交付。
- 使用 Pillow 脚本按像素处理：接近白色且低饱和的像素转透明，边缘像素按白色距离做半透明柔化，避免硬边。
- 登录页新增页面内 CSS：`main` 作为相对定位容器，背景图绝对居中、不可交互、低不透明度；登录表单放在前景。
- 表单卡片使用半透明白底和 backdrop blur，提高背景图存在感，同时保证输入内容可读。
- 保留登录、重置密码、注册入口的 DOM id 与业务逻辑。

## 实施计划

1. 更新登录页测试，要求标题为“这里是登录页面”，并要求引用 `yui-login-bg.png`。
2. 测试读取 PNG 头部，确认生成图片是 RGBA PNG。
3. 运行目标测试确认失败。
4. 用 Pillow 生成透明 PNG。
5. 修改 `shop/login/index.html`，加入背景图层和轻松标题。
6. 更新 `AGENTS.md` 协作记忆。
7. 运行测试并用浏览器验证桌面、移动端布局。

## 取舍

- 不使用 AI 抠图服务，保证处理过程可复现。
- 不把图片放到 CSS background 中，而使用 `img` 元素，便于浏览器加载、调试和测试资源引用。
- 不改 `shop/shop.js`，避免影响登录行为。
