# 首页雁阵：左边留白画一群雁

## 需求

用户看着侘寂首页（右边是竖排的名字和五句话），要求按项目里的 `chinese-aesthetic` skill，用极度克制、简洁的中国画画法，在左侧偏中心的空白处画一群大雁：让右侧像群山，左侧是鸟群飞过的留白。

## 构图

- 右边竖排字块的起笔从右到左一路降低（名字最高、「极度克制的审美。」最低），当作一排山的轮廓；雁放在它左边的天空里，领头的在左上，雁行向右下拖出去，尾上两只最小最淡，像刚从山后飞出来。
- 左边靠近语言切换、底部导航的地方一只也不放，留白还是主角。
- 11 只：领头一只、较长的一条雁行 5 只、较短的一条 3 只、远处两只；不画云、山、月、落款。

## 画法

- 一只雁 = 一笔翼（填色的弯月，两头收尖，粗在中段）+ 一点墨。翼姿四种：举翼、平翼、垂翼、斜翼，每只再转几度、缩放，所以没有两只一样。
- 全部用 `var(--ink)`，远的只降 `fill-opacity`（0.24 – 0.82），不引入第二种颜色。
- 整群套一个 feTurbulence + feDisplacementMap 滤镜，把边缘磨出一点毛笔的飞白，不是平滑的矢量。
- 一份 inline svg（`index.html` 里 `.scroll-head` 第一个子元素），没有图片、没有脚本，不增加请求。

## 动效

只复用墨洇：正文洇完之后（1.4 秒起），从领头那只开始每只相隔约 0.3 秒洇出来（opacity 0 → 1，blur 5px → 0，2.2 秒，同一条缓动）。只在 `html.ink-on` 下生效，开了「减少动态效果」就直接显示。没有飞动、视差或悬停。

## 尺寸

- svg 右缘 = `100vw − (gutter + 470px)`，贴着字块左缘；宽度取 `min(46vw, 800px, 100vw − gutter − 486px)`，所以 1100px、920px 宽时雁阵和字块之间仍有 60 – 70px 空隙，不会压到字。
- 窄于 900px 字块占满屏，不画雁阵。
- 1920 × 950 下领头那只翼展约 70px，量级和大字「悠」相当。

## 验证

- `npm test`：全部通过，新增一条「雁阵」测试（装饰性、只用墨色、只数 9 – 13、窄屏不画、淡入只在 `ink-on`、每只都有起笔延迟）。
- 用内置浏览器看了 1920 × 950、1100、920 三个宽度的位置和空隙；放大检查了单只雁的笔触。
- `wabi.css` 缓存号 `20261029-5` → `20261029-6`，所有页面一起升。

## 没做

- 手机上没有雁阵（竖排字块会换列占满屏，没有留白可画）。
- 没有改 `chinese-aesthetic` skill 的范本，雁阵是首页专用的点缀。
