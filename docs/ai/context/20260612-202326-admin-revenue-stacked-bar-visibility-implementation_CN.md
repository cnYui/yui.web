# Admin 收银排行三段柱可见性修正

## 背景

用户反馈 Shop 用户消费排行里的柱状图仍然像单色黑柱，希望每个用户的柱子按金额拆成三段，并用黑 / 白 / 灰表示：

- 缓存命中输入
- 缓存未命中输入
- 输出 token

今日和本月排行都要按相同规则展示。

## 设计判断

后端已经在 `customerSpendingRankings.today/month[].parts` 返回三段金额，前端也已经渲染堆叠柱。截图中仍然“不像拆分”的主要原因是视觉层：白色段在白色柱背景和页面白底里没有足够边界，图例白色点也不明显。

因此本次只做样式增强，不改变后端计费、排序或数据结构：

- 白色段保留白色含义，但加内描边。
- 图例圆点增加默认透明边框，让白色图例可以套用边界。
- 柱段增加轻微内部分隔，提升黑 / 白 / 灰之间的可识别性。

## 验证要求

- 静态测试必须确认构建后的 `styles/site.css` 包含白色段描边。
- `npm run build:css` 后再运行相关 Admin usage summary 和前端样式测试。
- 全量 `npm test` 通过后再提交并推送现有 PR 分支。
