# 首页线索墙：一张便签一个大标签，只用一种语言

## 背景

- 访客第一次进首页，面对软木板上的一堆便签，一眼看不出每张对应什么：标题是「谁是悠一？」「案件时间线」「行踪图」「笔记 · Field Notes」这种侦探味的叫法，旁边还挤着 `FILE 01`、`SUBJECT`、`CASE TIMELINE · 25 CASES · 6 AWARDS`、`机密 CONFIDENTIAL` 之类的小字，中英（日英）并排。
- 墙面按 1440 × 900 排版再整体缩放，笔记本上 k ≈ 0.6–0.8，手机上 k = 0.35：13–19px 的小字缩下来只剩 5–10px，根本读不了。
- 需求三条：能删的文字都删；关键信息用大字；只用一种语言标注，多语言靠词典适配（首页已有中 / 英 / 日三语，见 `20261010-160500-clue-wall-i18n-en-ja-implementation_CN.md`）。

## 做了什么

### 每张便签：一个大标签 + 一两行关键信息

| 便签 | 大标签（zh / en / ja） | 关键信息 |
| --- | --- | --- |
| 关于我（纸条） | 关于我 / About Me / 自己紹介 | 福井大学研究生；绿点 + 接受远程工作 |
| 肖像（拍立得） | 悠一 Yui / Yui / 悠一 Yui | AI Native Developer |
| 联系我（名片） | 联系我 / Contact / 連絡先 | 邮箱（电话和网址只留在「关于我」档案里） |
| 项目 | 项目 / Projects / プロジェクト | **25** 个项目 · **6** 个奖项（数字红色加大） |
| 商店 | 商店 / Shop / ショップ | CODE TRANSIT |
| 博客 | 博客 / Blog / ブログ | **7** 篇文章 |
| 旅行（行踪图） | 旅行 / Travel / 旅行 | 2024 → 2026 |
| 履历 | 履历 / Resume / 履歴書 | 福井大学 · 研究生 / AI Mage（东京）· 实习 / 国家能源研究院 · 实习 |
| GitHub 贡献图（只展示） | GitHub | 总数（绿色大字）+ 单位 · 年份，再加整年的方块图 |

- 大标签统一用毛笔体（`'Ma Shan Zheng'`），60–90px 设计尺寸；次要信息 19–26px。
- 删掉的：`FILE 0N` 编号、英文副标题（`WHO IS YUI?`、`CASE TIMELINE`、`TRAVEL LOG`、`SUBJECT · …`）、`机密 CONFIDENTIAL` 章和涂黑条、`金奖 AWARDED` 章、胶带标签（`福井大学 研究生 · 独立开发者 …`，和「关于我」重复）、「AI Native Developer：黑客松赛场上的开发者生存范式」那张不能点的便签、博客卡片里三条带日期的旧标题、履历卡里的证书行和 `WU JIANXIANG`、名片上的电话和网址。
- 墙上的道具也只用一种语言：执照只留「私家侦探」、桌面文件夹是 `2025` / `2026`、便条去掉 `MEMO ·` 前缀、抽屉标签 `MISC` 进了词典。
- 左侧原来放那张便签的位置，现在放「联系我」名片。

### 统计数字不再写死

- 旧版 `6 ENTRIES` 在新增《用 Claude Opus 5.5 做视频》之后就过期了。现在项目数、奖项数（`cat === 'award'`）、文章数由 `js/clue-wall.js` 的 `renderStats()` 数 `clue-data.js` 得出，填进词典模板 `wall.projects.stat` / `wall.blog.stat` 的 `{n}` / `{a}`；项目档案右上角的计数章同理（`projects.count`）。
- `index.html` 里仍写着中文静态版本（脚本没跑起来时看到的），`test/home-i18n.test.js` 会核对它和数据一致。

### 取件动画和档案页头跟着改

- 手里举着的封面只剩一个大标题，和墙上那张便签的标签是同一个词：`COVERS` 里的 `key` 直接指向便签标签的词典键，原来 21 个 `cover.*` 词条删掉了；标题字号按便签宽度估算缩小（`coverTitleSize`），日文「プロジェクト」放在窄便签上不会被裁。
- 档案标题 = 便签标签（`关于我`、`项目`、`博客`、`履历`、`旅行`、`商店`），测试守着两边一致。页头下面那行英文说明删掉了：商店档案里改成店名（`天才程序员中转站` / `Code Transit` / `天才プログラマー中継所`），博客档案里是一句操作说明，履历档案里是姓名；`机密`、`营业中 OPEN` 这类章去掉了英文或整个删掉。旅行档案里那句「见 FILE 02」没有了对应的编号，改成「见「项目」」。
- 底部提示、环境音按钮、「钉回墙上」也都是单一语言（`ui.hint`、`ui.sound.*`、`ui.back`），提示字号 12 → 15px。

### GitHub 贡献图卡片

- 去掉月份、星期、图例和同步时间（墙上缩小后看不清，也没人需要）；标题行是 `GitHub` + 总数 + 单位 · 年份，单位走词典（`github.unit` / `github.unit.one`），切语言时就地重写，不再请求。
- 方块改成按列数平分宽度（`grid-auto-columns: 1fr` + `aspect-ratio: 1`），53 列和 54 列的年份都不用改样式。
- `test/github-contributions-card.test.js` 随之调整：删掉两个月份标签测试，加上「单位跟着页面语言走」「词典没加载时退回英文」。

### 三语适配

- 词典里墙上和页头相关的键都改成单一语言；英文毛笔字母比汉字小得多，大标签放大一档；日文假名和汉字一样占整格，`:lang(ja)` 下「プロジェクト」缩到 48px、「ショップ」44px（`styles/clue-wall.css` 末尾的覆盖块，字号是按真实宽度量出来的）。
- 新增测试「墙上和档案页头的文案是单一语言」：zh / ja 里不许出现 4 个以上连续大写字母的英文词（`TOEIC` / `TOEFL` 登记在白名单），en 里不许夹汉字假名。拿改动前的词典跑同一套判断，会抓到 44 条混排。

## 没动的

- 档案里面的分节小标签和数据字段仍是中英并排：`教育 · EDUCATION`、`姓名 NAME`、`SUBJECT PROFILE · 基本档案`、项目筛选标签 `全部 ALL`、`city` 的 `大阪 Osaka`、案件徽章 `2ND PLACE` / `GOLD`、阅读器的 `CASE NOTE`、商店档案里的 `ADMIT ONE · 通行券` 等。这次范围是「首页上的卡片」，这些要统一的话单独做一轮（词典 + `clue-data.js` 的 `city` / `award` / 筛选标签 + 对应测试）。
- 行踪图图片 `travel-map-v4.webp` 里自带的标题（`行踪图 · 悠一` 和英文小字）是图片的一部分，改要重新渲染设计稿。
- `<title>` 和 `meta description` 没动。

## 验证

- `npm test`：143 个，142 通过；唯一失败的是 `Resume 页面所有 data-i18n key 都有中英日翻译`，是本机 Windows 工作区 CRLF 导致的老问题（干净的 `origin/main` 上同样 139 / 140，CI 的 Linux 上是绿的）。
- 浏览器里按 1440 × 900 看了中 / 英 / 日三种语言的整面墙，并用「把软木板克隆成 2D 覆盖层、按 1:1 平移」逐块看过卡片相邻处有没有互相遮字；`scrollWidth > clientWidth` 的溢出探针三种语言都是空的。手机尺寸（375 × 812）能读出每张便签的标签。
- 点开商店 / 项目档案看了手举封面的那一瞬间和落到桌上之后的页头；用锚点逐个打开了 6 份档案。
