# Account 模型总览浏览器验证

## 验证方式

- 启动临时 yui.web 服务：`http://127.0.0.1:4174`。
- 临时服务使用 `/tmp/yui-model-overview-*/shop.sqlite`，不使用真实 Shop 数据库。
- 从真实库读取最近已验证可用的托管 API key 并导入临时库，完整 key 未输出到终端或文档。
- 在浏览器中注册临时账号 `13800139997`，兑换临时邀请码。

## 验证结果

- 未兑换前，模型总览显示 `价格表回退`，只展示 `gpt-5.4` 和 `gpt-5.5` 两个价格表模型。
- 兑换后，模型总览显示 `实时模型`。
- 实时模型表格展示 5 个模型：
  - `codex-auto-review`
  - `gpt-5.3-codex-spark`
  - `gpt-5.4`
  - `gpt-5.4-mini`
  - `gpt-5.5`
- `codex-auto-review`、`gpt-5.3-codex-spark`、`gpt-5.4-mini` 标记为 `沿用 gpt-5.4`，价格为缓存命中输入 `¥0.25`、未命中输入 `¥2.50`、输出 `¥15.00`。
- `gpt-5.5` 显示独立价格：缓存命中输入 `¥0.50`、未命中输入 `¥5.00`、输出 `¥30.00`。
- 模型总览位于账户余额卡片上方，余额、充值、API key 和用量区域继续正常渲染。
