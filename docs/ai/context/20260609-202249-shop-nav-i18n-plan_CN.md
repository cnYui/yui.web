# Shop 顶部导航多语言计划

## 背景

用户指出个人站点顶部导航中的 `/shop/` 按钮在中文界面仍显示 `SHOP`，希望和其他导航项一样支持中日两种语言。

## 设计

- 复用现有 `js/lang.js` 的 `translations.common.*.nav` 公共导航翻译。
- 为 `zh/en/ja` 增加 `shop` 键：中文 `商店`，英文 `Shop`，日文 `ショップ`。
- 在 `updateCommonElements()` 中识别 `/shop/` 链接并使用公共翻译更新文本。
- 不改页面结构和样式，避免影响当前导航布局。

## 验证计划

- 先在 `test/shop-flow.test.js` 增加静态测试，确认 `js/lang.js` 包含 `shop` 三语翻译和 `/shop` 导航更新逻辑。
- 运行该测试，确认当前实现失败。
- 实现最小修复后重新运行测试。
- 运行项目测试，确认没有破坏现有流程。
