# 商店首页使用方法入口

## 背景

用户希望把 Codex CLI 公网 API 配置说明从兑换完成页扩展到商店首页入口：

- 首页新增一个灰色按钮。
- 点击按钮进入新页面。
- 新页面只展示使用方法。

## 设计

- 新增公开路由 `/shop/guide/`，作为购买前也能查看的使用说明页。
- 首页主操作区增加第三个灰色按钮“使用方法”，链接到 `/shop/guide/`。
- 使用说明页不展示真实 API key，统一使用 `sk-xx` 占位，并提示用户兑换完成后替换成自己的 API key。
- 兑换完成页仍保留动态使用说明，那里继续使用当前 result token 对应的真实 API key。

## 验证

- 测试覆盖首页按钮链接。
- 测试覆盖 `/shop/guide/index.html` 包含使用说明、公开 Base URL 和 `sk-xx` 占位。
- 浏览器验证首页按钮可见且说明页可打开。
