# 商店数据库中国时区时间存储计划

## 目标

把商店订单数据库中的兑换时间从 UTC `Z` 格式调整为中国东八区时间，格式使用带偏移量的 ISO 字符串，例如：

```text
2026-05-31T13:08:52.019+08:00
```

## 决策

- 不把时间简单加 8 小时后继续保留 `Z`，否则真实到期时刻会被改变。
- 使用 `+08:00` 偏移量保存同一个真实时间点，便于人工查看，也能让 `new Date(...)` 正确解析到原始时间点。
- 新兑换写入 `redeemed_at` 和 `expires_at` 时统一使用中国时间。
- 当前已有订单的 `redeemed_at` 和 `expires_at` 一次性迁移为等价的中国时间。

## 验证

- 新增测试确认新订单的 `redeemed_at` 和 `expires_at` 都以 `+08:00` 结尾。
- 迁移后查询当前 SQLite，确认历史订单时间不再是 `Z`，且到期仍保持兑换后 31 天。
