# Admin 用户消费排行堆叠柱设计与计划

## 背景

用户希望 `/shop/admin/` 的「Shop 用户消费排行」不再只显示每个用户一个单色总金额柱，而是把单根柱拆成三段，用黑 / 白 / 灰表示缓存命中输入、缓存未命中输入和输出三类扣费金额。

## 设计

- 后端 `customerSpendingRankings.today/month` 继续只包含 Shop 托管用户，不包含 Local / 未托管。
- 每个排行项保留 `phone`、`chargeNanos`、`chargeAmount`，用于排序和柱顶总金额。
- 每个排行项新增 `parts`：
  - `cache_hit_input`：缓存命中输入金额
  - `cache_miss_input`：缓存未命中输入金额
  - `output`：输出 token 金额
- 拆分金额按每条扣费记录的 `price_version` 计算，继续兼容旧价格版本，不按当前价格重算历史。
- 前端每个手机号仍是一根柱，但内部使用三个堆叠段展示三类金额。
- 颜色映射：
  - 黑色：缓存命中输入
  - 白色：缓存未命中输入
  - 灰色：输出 token
- 今日 / 本月切换保留，两种周期都展示相同拆分逻辑。
- 排名仍按总扣费金额从高到低排序。

## 实施计划

1. 先补后端测试：断言用户排行项包含三类金额拆分，且 Local 被排除。
2. 补前端测试：断言 Shop 用户消费排行使用堆叠柱段和黑白灰图例。
3. 修改后端排行聚合，把每个手机号从单值金额改为总额 + 三类金额。
4. 修改前端柱状图渲染，按 `parts` 生成堆叠段。
5. 补充必要 CSS 并执行 `npm run build:css`。
6. 运行测试和浏览器局部渲染验证。
