# 兑换完成页使用方法移除与邀请码清理

## 背景

用户希望：

- 兑换完成后的 `/shop/key/` 不再展示使用方法。
- 已使用过的兑换码/邀请码从数据库中删除，只保留未使用的邀请码。

## 决策

- 使用方法保留在公开的 `/shop/guide/` 页面。
- `/shop/key/` 只展示订单和 API key，不再展示配置说明。
- 数据库只删除 `invite_codes.status != 'unused'` 的邀请码记录。
- 不删除 `orders` 和 `api_keys.status = 'used'`，因为它们承载已购买用户的手机号查询和 API key 使用记录。

## 验证

- 测试需要覆盖：兑换完成页脚本不再渲染使用方法。
- 数据库清理后检查 `invite_codes` 只剩 `unused`。
