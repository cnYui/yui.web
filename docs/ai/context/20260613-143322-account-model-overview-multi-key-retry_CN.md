# Account 模型总览多 key 探测修正

## 背景

自查 PR diff 时发现：同一个账号如果有多把已兑换 API key，而最新一把暂时不可用或未加入中转站入口，模型总览不应直接回退价格表。

## 修正

- `GET /api/account/model-overview` 会按当前账号订单顺序遍历可解密 API key。
- 如果某把 key 请求 `/v1/models` 失败或返回空模型列表，继续尝试下一把 key。
- 只有所有 key 都无法拿到模型列表时，才回退到本地价格表。

## 验证

- 新增测试：`Account 模型总览接口会跳过不可用托管 API key 继续探测同账号其他 key`。
- 已先确认该测试红灯，再实现循环探测并确认通过。
