# 首页线索墙：点开便签后的子页面（档案）重做

## 背景

- 子页面是点开便签后摊在桌上的一张 1280 × 760 的纸，再按窗口缩放。旧版里的字只有 11–15px（设计尺寸），缩到 0.5–0.9 倍之后实际只有 6–13px；照片只有 124px 高（旅行）、130px 高（项目）。再加上分类标签（项目 4 类、旅行 15 个城市）、印章、胶带、倾斜的小纸片、红线和图钉，一页塞了太多东西，照片显得更小。
- 要求：字更大、更结构化；履历做成 A4 纸、可滚轮滚动；照片页直接呈现照片、不分类；获奖页（项目）不分很多类，直接展示，或做成时间线、一个节点一场比赛；装饰全部去掉，只留最简单的返回按钮和大字。

## 做了什么

### 共用骨架

- 每份档案：左上一个深色返回键（「← 返回」，不再是「← 钉回墙上」）+ 旁边 76px 的大标题 + 下面一整块内容区 `.cw-pane`（1168 × 616，里面用滚轮 / 触控板 / 键盘上下键、翻页键滚动，可聚焦）。所有纸统一一个底色，履历底色略深，让白色的 A4 看得出边。
- 纸摊开后的缩放由 `k × 0.9`（k 是整面墙 1440 × 900 的缩放，纸只占窗口的一半多）改成 `sheetScale()`：宽、高各算一个再取小的（`W / 1280 × 0.96`、`H / 760 × 0.92`，上限 1.5）。1440 × 900 下纸从 0.9 倍变成约 1.08 倍，面积大了约 44%，里面的字再叠加放大。
- 顺手修了一个原来就有的问题：「减少动态效果」在桌面宽度下，`renderSheet` 把 transform 清空，纸以 1280 × 760 的原始尺寸堆在左上角。现在只有窄屏才清空，减少动态效果只是不演过渡。
- 去掉的：印章（`.cw-stamp`）、胶带、倾斜的小纸片、档案里的红线和图钉（`.cw-file-strings`）、分类标签（`.cw-tabs` / `.cw-tab`）、项目计数章、「最近目击」列表、商店的通行券 / 线索 / 营业中章、博客阅读器的「案卷 CASE NOTE」和「AI」章、稿纸页眉页脚。

### 履历：A4

- 两张 A4（宽 800、`min-height` 1131，比例 210 : 297），内容比一张高就自己长高。第一张：姓名（78px）、职业、邮箱、教育、经历；第二张：技能（两列）、证书、奖项。正文 22px，条目 24–26px，章节标题 26px；以前是 13–15px。
- 在内容区里用滚轮上下滚。下载 PDF 按钮放在标题右边（`left: 560px`）：右上角那一块会被语言切换和环境音按钮盖住。
- 标签改成单一语言（教育 / Education / 学歴），不再是「教育 · EDUCATION」。手机和电话不进公开页，原来就没有。

### 项目（获奖）：时间线

- 25 个项目按时间倒序排成一条时间线：左边日期，中间是线和圆点（获奖的是红色实心点，其余是空心点），右边是大图（928 × 372）+ 标题 + 城市 + 说明。获奖的节点标题旁边有「获奖」两个字（词典键 `projects.award`），按 `cat === 'award'` 判断，不再显示英文大写的 `2ND PLACE` / `GOLD`。
- 每个节点正好等于内容区的高度（616px），`scroll-snap-type: y mandatory` + `scroll-snap-stop: always`：滚轮一格翻一个，快速滚动也不会一下翻过好几个。窄屏上取消吸附，节点按内容长高。
- 没有任何分类标签了；数据里的 `cat` 只用来标获奖和数墙上便签上的奖项数。带外链的节点把「查看 →」放在城市同一行，不让它撑破一屏。

### 旅行（照片）

- 一本相册：先是路线图（高 400，外框贴着图片），后面 26 张照片两列排开，每张照片 340px 高（以前 124px），下面是标题（38px 毛笔体）和一两行说明，同一行的两张卡等高。去掉了 15 个城市标签、最近目击列表和英文副标题。

### 关于我、博客、商店

- 关于我：左边照片（380 宽，头像裁切框到脸）+ 标题；右边一个可滚动的区域：基本信息（五行，26px）、三个隐喻、VIBE / SPEC / HARNESS、关键词标签、联系方式。去掉了印章、倾斜的 VIBE / SPEC / HARNESS 小纸片、关键词的倾斜便签和红线图钉。
- 博客：列表是两列大卡片（照片 250px 高 + 日期 + 31px 标题 + 三行摘要）；阅读器左边是概要（标题、日期、配图、摘要、标签、「← 全部文章」），右边是正文稿纸（正文 22px，小标题 32px / 26px）。
- 商店：左边店面图（700 × 480）+ 右边店名、Sub2API、「进入商店 →」大按钮。通行券、线索、营业中章都去掉了，店面图本身仍是入口。
- 分节标签、按钮上的小标签全部改成当前语言一种（`about.dt.*`、`about.meta.kicker`、`about.contact.title`、`resume.h.*`、`resume.download`、`reader.back`、`link.view`、`shop.ticket.cta`），`test/home-i18n.test.js` 的「单一语言」测试也把它们登记进去守着。

### 窄屏（< 900px）

- 单列，整张纸自己滚动：返回键固定在左上，A4 变成宽度 100% 的纸，时间线靠左（日期在节点上面），相册一列，博客一列。字号按手机单独设置（正文 16–19px）。

### 数据和词典

- 删除不再使用的 `projectCats`、`travelCities`（`js/clue-data.js` 和英 / 日译文包各两份）和对应的词典键（`cat.*`、`projects.count`、`travel.r1–r4.*`、`shop.clue.*` 等）。项目和旅行数据里的 `award`、`rot`、`en` 字段没有删：英日译文按下标对齐，改它们要连着译文包一起动，不在这次范围。
- `?v=` 提到 `20261014-4`：`clue-wall.css`、`clue-wall.js`、`clue-i18n.js`、`clue-data.js`。`clue-board.js` 没改，保持 `-3`。

## 验证

- 浏览器里逐页看了 6 份档案的桌面布局（中文），并用探针在中 / 英 / 日三种语言下查横向溢出和时间线节点高度：没有横向溢出；25 个节点最高 587px，都在一屏（596px）以内。吸附实测：`scrollTop` 700 → 616、1948 → 1848，都落在节点边界。
- 手机宽度（375）下 6 份档案 × 3 种语言：没有横向溢出。
- 测试：新增 `test/home-clue-files.test.js`（装饰全部去掉、六份档案骨架一致、内容区可聚焦滚动、A4 比例和字号、时间线一屏一个节点、相册两列大图、纸的缩放）；其中字号下限那条扫描了 58 条规则，除代码块的小标签外都不小于 17px。更新了 `home-i18n` / `home-clue-wall` 里和分类、计数章有关的断言。
- 没有验证的：触屏和真实滚轮的吸附手感；「减少动态效果」下的桌面布局（改动很小，但没法在这里模拟）。
