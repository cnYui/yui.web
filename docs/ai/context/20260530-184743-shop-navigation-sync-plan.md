# Shop 导航同步计划

## 背景

当前新增了 `/shop/` 商店模块，但项目中已有多个静态页面的顶部导航仍未包含 Shop 入口。用户要求检查所有路由页面，缺少的同步补齐。商店页面统一使用中文，不接入多语言。

## 必须修改

- 扫描项目内所有 HTML 页面，不包含 `node_modules/` 和 `superpowers/`。
- 对已有主导航页面补充 `/shop/` 链接。
- 对移动端菜单也同步补充 `/shop/` 链接。
- Shop 模块页面保持中文文案，不新增 `data-i18n`。

## 取舍

- 只同步导航，不重构页面头部组件，避免大范围模板化改动。
- 页面当前导航结构不完全一致，因此采用机械替换：在 `Anime` 导航项后追加 `Shop`。
- Shop 页面本身已有 Shop 链接，不额外改成多语言。
