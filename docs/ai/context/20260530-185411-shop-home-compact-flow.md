# Shop 首页紧凑化调整

## 背景

用户指出 `/shop/` 首屏右侧的大卡片过高，让主页显得冗长。希望删除该组件及其内容，并把下方三条流程说明移动到首屏中竖向排列。

## 修改方案

- 删除右侧大预览卡片，包括 `31 days access`、价格和“邀请码兑换”标签。
- 删除下方独立三列流程区块，避免重复占用页面高度。
- 将三条流程说明移动到首屏右侧，采用竖向列表：
  - `payments` 私下付款
  - `password` 邀请码兑换
  - `event_busy` 31 天有效
- 保持商店页面中文，不接入多语言。

## 预期效果

首页首屏更紧凑，核心信息集中在一屏内：左侧介绍和操作按钮，右侧展示购买/兑换/有效期流程。
