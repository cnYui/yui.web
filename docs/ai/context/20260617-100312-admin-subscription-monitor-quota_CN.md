# 管理员加入用户额度监控

## 需求

管理员手机号 `15951875192` 需要出现在 Admin 的用户额度监控面板中，并按 59 元套餐展示额度。

## 设计

- 修改范围限定在 `/api/admin/subscription-users` 的额度监控视图。
- 管理员账号使用内置监控额度，不走用户购买和审批流程。
- 管理员固定映射到 `sub_59_daily_49_usd`，每日额度 `49` 美元，即 `49000000` micros。
- 今日已用额度仍按 `api_usd_charge_records.phone + quota_date` 的真实扣费记录统计。
- 该逻辑不影响普通用户套餐、不影响加量包优先级、不改变 Account 个人页面购买流程。

## 测试

新增后端测试要求：已存在管理员账号时，`/api/admin/subscription-users` 返回管理员记录，套餐为 `59 元订阅池`，每日额度和剩余额度为 `49000000`。
