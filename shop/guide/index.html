Sub2API 配置使用方法

朋友只使用 Sub2API 用户 key 和 Sub2API Base URL。不要使用 CLIProxyAPI 的内部 key；CLIProxyAPI 只保留在内网给 Sub2API 作为上游。

把下面这段文字发给另外一个 AI，让它根据文字内容去修改 Codex 配置目录里的 config.toml 和 auth.json。改好之后重启 Codex 就能使用。

export OPENAI_BASE_URL="https://你的-sub2api-域名/v1"
export OPENAI_API_KEY="Sub2API 分配给你的 API key"

# Codex CLI 使用 Sub2API 配置说明

请求统一发到 Sub2API，不要直接访问 CLIProxyAPI。认证方式只使用 HTTP Header：

Authorization: Bearer $OPENAI_API_KEY

## config.toml

```toml
model_provider = "sub2api"
model = "gpt-5.4"
model_reasoning_effort = "medium"

[model_providers.sub2api]
name = "sub2api"
base_url = "https://你的-sub2api-域名/v1"
wire_api = "responses"
```

## auth.json

```json
{
  "OPENAI_API_KEY": "Sub2API 分配给你的 API key"
}
```

## 验证

```bash
curl -sS "$OPENAI_BASE_URL/models" \
  -H "Authorization: Bearer $OPENAI_API_KEY"
```

不要使用 CLIProxyAPI 的内部 key；朋友只使用 Sub2API 用户 key。不要把 API key 放到 URL、query 参数、x-api-key 或其他 header 里。
